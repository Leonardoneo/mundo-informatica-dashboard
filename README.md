# 🖥️ Dashboard Executivo - Mundo da Informática

Este repositório apresenta o desenvolvimento de um painel gerencial (*Dashboard*) analítico e interativo construído em **Microsoft Excel** para a empresa fictícia **Mundo da Informática**, desenvolvido como parte do projeto prático da DIO.

---

## 📊 Sobre o Projeto
O objetivo deste projeto foi estruturar um modelo de inteligência de negócios voltado para o comércio de equipamentos de informática e acessórios. O painel centraliza as principais métricas comerciais da empresa para apoiar a tomada de decisão executiva nas áreas de vendas, margem de lucro, desempenho regional e análise de mix de produtos.

---

## 📂 Estrutura da Planilha
A workbook do Excel está organizada nas seguintes abas:
1. **`Dashboard`**: O painel visual executivo contendo cartões de KPIs em destaque (Faturamento Total, Lucro Bruto, Margem e Quantidade), gráficos dinâmicos e **Segmentações de Dados (*Slicers*)** interativas por *Categoria*, *Região*, *Ano* e *Mês*.
2. **`data`**: Base de dados transacional contendo o histórico de vendas detalhado com 60 pedidos registrados no ano de 2026.
3. **`Calculos`**: Aba de suporte e estruturação de tabelas auxiliares, fórmulas e agregações para alimentar os visuais do dashboard.

---

## 📈 Principais Métricas e Indicadores (2026)
* **Faturamento Total**: R\$ 295.600,00

* **Região Líder**: *Sudeste* (com R\$ 99.050,00 em vendas).
* **Carro-Chefe (Produto)**: *Notebook Pro* (maior faturamento individual).
